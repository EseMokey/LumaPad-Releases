# Lumapad downloads

**[Download Lumapad](https://esemokey.github.io/LumaPad-Releases/)**: the newest version, what's new, and how to install it.

- **Full releases** are the [releases](../../releases) without a "Pre-release" label. Lumapad installs them by itself once it's on your PC.
- **Betas** (Pre-release) are for testers: the [tester page](https://esemokey.github.io/LumaPad-Releases/beta/) and Settings > Updates in Lumapad (with the tester code).
- **Bugs and ideas:** Help > Send feedback in Lumapad, or [open an issue](../../issues/new/choose).

This repository only holds the installers, the download pages and the feedback forms. It's updated by the release workflow, so changes made here by hand are replaced on the next release.
