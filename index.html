Lumapad

Your PlayStation, Xbox and Switch controllers in every PC game: real rumble, adaptive triggers, a profile for each game and almost no delay.

Looking for the newest version... For Windows 10 and 11 (64-bit)

One player per controller

Games see exactly one controller per person, with no double input, up to 12 players.

A profile for every game

Remaps, deadzones, gyro aim, triggers and lights switch by themselves when a game starts.

Quick Menu in any game

Hold PS and press L3: change profile, rumble, triggers and lights without leaving the game.

Keeps itself up to date

New versions install by themselves when you're not playing. Never during a game.

Install it

  1. Download and run Lumapad-Setup.Windows may say it protected your PC (the setup isn't signed yet): choose More info, then Run anyway.
  2. Keep both drivers ticked.HidHide stops games seeing two controllers; USBIP makes the virtual controller. Restart if the setup asks.
  3. Plug in your controller and play.Lumapad starts with Windows and sits in the tray. That's it.
