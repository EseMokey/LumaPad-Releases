How testing works

  1. Put the tester code into Lumapad too.Settings > Updates > Tester. Then every beta and older version shows up there and you pick which one to install. Betas never install by themselves.
  2. Tell us what you find.Help > Send feedback > Beta feedback, with the log ticked. Bugs, ideas and "this feels great" all help.
  3. When a full release comes outyou move to it by yourself, so you're never stuck on an old beta.
